# Projeto Frontend

Três desafios de front-end (HTML, CSS, Bootstrap 5 e JavaScript) que consomem a API da trilha de backend.

## Como rodar

1. Instale o Node.js 18 ou superior.
2. Suba a API (ou o mock, enquanto o backend não estiver pronto):

```bash
   npx @stoplight/prism-cli mock contracts/openapi.yaml --port 5080
```

3. Abra a pasta `projeto-frontend` no VS Code.
4. Clique com o botão direito no `index.html` de um desafio e escolha **Open with Live Server**.

## Configuração

A URL da API fica em `shared/config.js`.
